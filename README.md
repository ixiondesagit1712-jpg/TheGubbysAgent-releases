# The Gubbys Agent — Releases Oficiales

Este repositorio aloja únicamente los manifiestos firmados con Ed25519 (`manifests`) y los instaladores compilados oficiales (`vX.Y.Z`) de **The Gubbys Agent** para Windows x64.

- El código fuente completo se mantiene en un repositorio privado independiente.
- Los paquetes de instalación automática son verificados criptográficamente (Ed25519 + SHA-256) antes de aplicarse.
- Si actualizas desde `v0.6.0` o anterior sin autoactualizador integrado, instala `v0.6.1` manualmente una sola vez para activar las actualizaciones automáticas globales.
